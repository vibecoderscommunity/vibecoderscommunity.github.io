# Website UI kit

Interactive mock of the Vibe Coders Tokyo site: landing page (hero, next meetup, past-event grid, newsletter band) and a past-event recap view. Click the header nav to switch views; newsletter form and RSVP are fake-interactive.

Built from the design-system components (Header, Button, Card, Tag, Input, Select, MultiSelect) — no re-implementations. Event content comes from the real posters in `assets/events/`.
