Pixel-styled button for all actions; Silkscreen caps label, ink border, hard offset shadow.

```jsx
<Button>RSVP now</Button>
<Button variant="secondary" size="sm">Details</Button>
<Button variant="flavor" flavor="var(--lime)">Join waitlist</Button>
```

Variants: `primary` (red), `secondary` (white), `inverse` (ink), `flavor` (pass an event-flavor token). Sizes sm/md/lg. Hover lifts, press sinks — built in.
