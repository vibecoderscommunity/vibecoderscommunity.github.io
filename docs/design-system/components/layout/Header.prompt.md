Site header bar; pixel wordmark left, mono nav right, active link underlined red, optional CTA Button.

```jsx
<Header links={[{label:"Events",href:"#events"},{label:"About",href:"#about"}]} activeHref="#events" cta="RSVP" />
```

Pass `logoSrc="assets/logo.avif"` to use the logo image instead of the type wordmark.
