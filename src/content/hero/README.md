Images for the rotating photo frame in the hero, on the landing page.

Drop image files in this folder and they appear in the rotator, **sorted by
filename**. Nothing else to edit.

    01-packed-room-at-google-shibuya.jpg
    02-gemma-workshop.jpg
    03-pizza-queue.jpg

The caption shown under the frame comes from the filename: the leading `NN-`
and the extension are stripped, and dashes become spaces. So the first file
above reads as `PACKED ROOM AT GOOGLE SHIBUYA`. To change a caption, rename the
file.

Supported: .avif .webp .png .jpg .jpeg .gif .svg

They are displayed as a square, so square or centre-weighted images work best.

**While this folder has no images in it**, the rotator falls back to the event
posters so the hero is never empty. Adding a single file here replaces that
fallback entirely.

This README is ignored (it isn't an image).
