1. Sumit Chandel (Firebase Genkit & AI Developments)
  - Role: Developer Relations Engineer for Firebase at Google.
  - LinkedIn: [Sumit Chandel](https://www.linkedin.com/in/sumit-chandel-a273792/?lipi=urn%3Ali%3Apage%3Ad_flagship3_pulse_read%3BCNuvPRGnSGS8YcSWy6hZKw%3D%3D)
  - Talk Summary: Discussed the "existential" transition of software development, positioning us at "Step 1" where we integrate AI into the massive ecosystem of pre-2022 apps. Demonstrated a "friendly movies app" using Firebase Genkit. He showed how to easily add AI features to a standard app by importing the Firebase SDK and configuring the Gemini 3 Flash model.
  - Tools Mentioned:
    - Firebase Genkit (SDK for building AI features)
    - Gemini 3 Flash (Model used for the demo)

2. Cedric (Human Brain & AI)
  - Role: Computer Science Graduate & Speaker.
  - Linkedin: https://www.linkedin.com/in/cedric-camerman/
  - Slides: [View Slides](https://drive.google.com/file/d/1SNCXk4X8ziftOlwBCApYht_DatYTVBqJ/view?usp=sharing)
  - Talk Summary: Focused on the "human bottleneck" in AI-assisted coding: Cognitive Load. Explained that while AI lets you switch roles rapidly (Architect ↔ Developer ↔ Tester), this context-switching drains your brain's energy. Proposed managing your "daily cognitive budget" (or token limit) by treating your brain like a muscle

3. Prashant Anand (Better Frontend)
  - Role: Machine Learning Engineer (ex-Mercari) & Newsletter Author.
  - LinkedIn: [Prashant Anand](https://www.linkedin.com/in/primaprashant?lipi=urn%3Ali%3Apage%3Ad_flagship3_pulse_read%3BCNuvPRGnSGS8YcSWy6hZKw%3D%3D)
  - Talk Summary: Addressed the "Generic UI" problem where AI-generated sites often converge on predictable designs. Shared his workflow using the "Front End Design" skill—an official Anthropic plugin for Claude Code (the CLI tool). This plugin acts as a specialized designer agent that can be installed into your environment to enforce better aesthetics.
  - Tools Mentioned:
    - Claude Code "Front End Design" Skill (The specific skill/plugin mentioned)
    - Agentic Coding Weekly (Prashant's newsletter)
    - Google Anti-Gravity (New local IDE tool mentioned as a "free alternative to Cursor")
    - GitHub Copilot

4. Sean (LanguageBank)
    - Role: Product Designer.
    Linkedin: https://www.linkedin.com/in/seanyeoh/
    - Slides: [View Slides](https://docs.google.com/presentation/d/1JEMBkjP8au_4bv4Ybu8y0Rf_DPmTeXmALwUrpZzMjnw/edit?slide=id.g3bbe66b6ddd_0_63#slide=id.g3bbe66b6ddd_0_63)
    - Talk Summary: Showcased LanguageBank, an iOS app he built to streamline his Japanese learning workflow. Detailed his development process: using OpenAI Whisper for transcribing speech and Supabase for handling authentication and backend data. Shared insights on the "builder" experience: The app took only 5 days to build using AI agents (Cursor), but the App Store review process took longer. He used AI to debug the specific rejection reasons from Apple.
    - Tools Mentioned:
      - Supabase (Used for Auth/Database)
      - OpenAI Whisper (Transcription)
      - Xcode (iOS Development)
      - LangTool (Mentioned for prompt experimentation)
