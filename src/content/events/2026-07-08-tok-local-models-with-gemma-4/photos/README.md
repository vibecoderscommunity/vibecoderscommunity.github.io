Drop event photos in this folder and they appear in the "Photos" grid on the
event page, sorted by filename — no code or frontmatter changes needed.

  01.jpg, 02.jpg, 03.jpg …

Supported: .avif .webp .png .jpg .jpeg .gif .svg
Any event folder can have one; create `photos/` if it isn't there yet.
