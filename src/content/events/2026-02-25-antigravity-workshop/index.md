Top tips for Google Anti-gravity

- 🥳 Control your tokens by switching modes. Use Fast Mode for simple terminal commands and Planning Mode for complex architectural tasks.
- 🥳 Use the browser extension. The agent can read the DOM, visually reproduce web app bugs, and generate a video recording of the fix to show you its work.
- 🥳 Keep rules modular. Create isolated agent "Skills" for specific workflows to avoid overloading the context window with too many instructions at once.
