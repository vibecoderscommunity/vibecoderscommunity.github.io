Thanks to everyone who joined yesterday's workshop! A huge thanks to @jetha  for leading the clear, relatable and practical session 🙂 It was amazing to see many of you code your first app with pure creativity and passion. 

Takeaways: 

- 🥳 Use Google AI Studio for rapid prototyping. Start with a basic idea and use the chat to iterate instead of trying to write a perfect initial prompt. 

- 🥳 Use images to drive UI design. We saw a basic Tic-Tac-Toe game turn into a Persona 5-style interface just by uploading a reference screenshot. 

- 🥳 Reserve API calls for complex tasks. Use the Gemini API for tasks like image recognition, but keep simple logic local to reduce costs and latency.
