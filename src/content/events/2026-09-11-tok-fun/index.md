We celebrated our 10th meetup with a night dedicated to the fun side of vibe
coding. 🥳 Silly games, tiny personal apps, delightful micro-interactions —
anything built purely because it made you smile. 🌈

## Demos

- 👾 **[Dowyn](https://apps.apple.com/jp/app/dowyn-habit-task-tracker/id6760456371)**
  by Ian: an incredible iOS productivity app gamifying your to-dos with a
  monster-catching battle system, built using Claude Code and Firebase.

- 🛋️ **Agent therapist** by Ankha: a hilarious CLI tool that acts as a therapist
  for AI agents, reading telemetry data to diagnose context exhaustion psychosis
  using Gemini Flash.

- 🐾 **Custom slide engine** by 🌙 Xinni C.: a bespoke presentation engine coded
  from scratch with matter.js to support interactive HTML design prototypes and
  a custom cat-paw cursor.

- 🍌 **Banana Studio** by Thu Ya Kyaw: an awesome event booth app turning user
  photos into culturally themed sticker sheets using Gemini, complete with a
  super-admin panel to track prints.

- 🎧 **3D interface explorer** by Nino: a gorgeous design exploration tool for
  Spotify and Netflix interfaces, using natural language physics for
  interactive animations and loops.

- 🎬 **AI video generator** by Raymond: a multi-agent workflow using InVideo and
  VMake to automate the creation of short, humorous videos from long source
  audio files.

- 🎮 **[Steam Deck OCR](https://scallsen.github.io/japanese-lookup/)** by Simon:
  a custom Decky plugin built with Claude Code that scans Japanese games using
  local OCR and exports vocabulary directly to Anki via QR codes.

Thank you to everyone who came along and shared what they built for fun! 👏
